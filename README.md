# Text animation skill

A Claude skill for adding text animations to React Native and React / Next.js projects.

- **Split reveal**: letters or words slide up from behind a mask, staggered
- **Typing**: characters appear one at a time with a cursor and human pacing
- **CLI mode**: terminal-style typing with dark and light themes and optional window chrome (macOS, tabs, minimal)

Includes reduced-motion and screen reader handling, which can be turned off for recordings and demos.

## Install

Download `text-animation.skill` from the latest release and open it, or copy the `text-animation` folder to `~/.claude/skills/`.

## Use

Ask Claude for a text reveal, a typing effect, or terminal-style typing, or type `/text-animation`.
